# STARBASE - Lanna  & Aliyah
 - BRIEF DESCRIPTION
From my memory, I think their project consisted of being a worker, and having to clock in to work, and then search for celestial objects. With the data, it would overwork the employees while the company proffited the most. 

 - SUGGESTIONS
 I really liked the terminal aesthetic. Visually, this is what I envision in my mind when I think about data. The protagonist's nerd friend hacks into the system by clicking on random keyboard buttons and then get access to the wireframe and BOOM!, they saved the world. I also loved the political aspect, and how it is very realistic to the capitalistic system we live under. 
 
# CatClaim - Amelie & Philippe
 - BRIEF DESCRIPTION
Their project consisted of a digital gallery/museum of cat pictures that would be displayed on 3d cubes all around the scene. Each added image would add a cube with the imported image on it. 
- SUGGESTIONS
I thought this project was really nice. It had quite surpassed my expectations as I did not expect it to be done on three.js. The 3d scenery made it really nice, as the player could walk around the scene and take a closer look. It would be great to allow users to add some basic information, like the cat's name, the user's name, etc. Sometimes cat pictures can get even cuter when some context is given. Another way to play with data collection is for each image to be paired with time, date and location information of when the picture was posted; some way to connect with strangers through cat pictures. 

# Ascii converter - Lilin
 - BRIEF DESCRIPTION
Her project consisted of a webpage where people could import their picture and it would be converted into ascii form. I think this was such a nice way to create an art project driven by data. A lot of the times, when I think of data, I think of numbers, big and long numbers. Through that project, I learned that ASCII stands for American Standard Code for Information Interchange which changes characters into numerical figures. 
- SUGGESTIONS
I think it would awesome if people could import videos or gif images and have them also be converted into ASCII. The motion capture aspect of it would be really nice to see.
